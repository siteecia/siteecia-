Integração com Google Sheets

Conecte seu painel diretamente a uma planilha do Google onde os formulários do seu site são salvos.

📖 Como configurar a integração no Google Sheets (Passo a Passo)

  1. Abra a planilha do Google Sheets que recebe os contatos do seu formulário.
  2. Vá no menu Extensões > Apps Script.
  3. Substitua o código existente pelo script abaixo e clique em Salvar:
function doGet() { var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet(); var data = sheet.getDataRange().getValues(); // Remove a primeira linha (cabeçalho) se houver if (data.length > 0) data.shift(); return ContentService.createTextOutput(JSON.stringify({ dados: data })) .setMimeType(ContentService.MimeType.JSON); }
  1. Clique em Implantar > Nova implantação.
  2. Escolha o tipo Web App, defina Quem tem acesso como "Qualquer pessoa" (Anyone) e clique em Implantar.
  3. Copie a URL do Web App gerada e cole no campo acima!
